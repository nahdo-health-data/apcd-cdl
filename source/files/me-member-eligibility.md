# B. Member Eligibility File (ME)

A member eligibility file is a data file composed of demographic information for each member eligible for medical, pharmacy, and dental benefits for one or more days of coverage at any time during the reporting period. Data suppliers must provide a data set that contains information on every covered plan member, regardless of whether the member utilized services during the reporting period. One record per member, per month, per plan, is required. For example, if a member is covered as a subscriber and a dependent on two different policies during the same month, two records must be submitted. If a member has two contract numbers for two different coverage types, two member eligibility records must be submitted. However, if a member has more than one record due to an address or other change, send only the most current record.
