# Changelog

Each entry says what changed and why, and points to the data maintenance request (DMR) or errata id where there is one. Published versions of the APCD-CDL are tagged in git.

## APCD-CDL v4.0.1

Digitized from the published APCD-CDL v4.0.1 (February 2025). The element tables for all ten files, Appendices J and K as code sets, Appendix L as reference prose, and the front matter are now structured source. The content is as published, including known errors, which are corrected through maintenance and not in the digitized copy.

## CMS-to-CDL crosswalk v1.0 (October 2026)

First version of the crosswalk from the CMS Medicare fee-for-service Research Identifiable Files (CCW RIF) to APCD-CDL v4.0.1, covering the Member Eligibility, Medical Claims, and Pharmacy Claims files. Imported as CSV from the final mapping workbook.
